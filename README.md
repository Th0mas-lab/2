# 纳指观察

纯静态行情仪表盘，可部署到 GitHub Pages。页面不需要本机服务、构建工具或境外脚本/CDN。

## 发布到 GitHub Pages

1. 在 GitHub 新建一个公开仓库。
2. 将本仓库的文件上传到仓库根目录，确保 `index.html` 位于根目录。
3. 打开仓库 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**，分支选 `main`，目录选 `/ (root)`，然后保存。
5. 等待 GitHub Pages 部署完成，访问页面上显示的 `https://<用户名>.github.io/<仓库名>/` 链接。

## 数据来源和限制

- 行情与历史 K 线：东方财富公开行情接口。
- 国际市场资讯：东方财富公开资讯接口。
- 价格、区间、技术指标及趋势判断均由浏览器本地计算；新闻来源的文章链接会打开东方财富网站。
- “走势复盘”展示区间收益、最大回撤、高低振幅、核心标的同期涨幅对照和区间新闻关键词线索；新闻覆盖不足时会明确显示覆盖日期，不会用区间外新闻解释历史走势。
- 页面数据请求直连国内数据接口。数据可用性、延迟和跨域策略由数据提供方决定；服务方变更接口时，页面可能需要更新。
- 本站是静态页面，不提供离线行情，也不构成投资建议。
